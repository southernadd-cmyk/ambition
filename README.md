# BTEC IT Pathfinder

A static, privacy-friendly career ambition and target-setting quiz for **Year 12 BTEC IT students**.

## What it does

- Guides students through 12 short career-planning questions.
- Matches interests to three digital/IT role families.
- Suggests a route to research: university, degree apprenticeship, apprenticeship, direct employment, or keeping two routes open.
- Lets the student select the direction they prefer.
- Generates an editable ambition statement and five practical Year 12 targets.
- Includes reflection prompts.
- Can copy, download, print or save the completed action plan as PDF.
- Stores answers only in the student's browser using `localStorage`.
- Sends no student data to a server.

## GitHub Pages

This project contains only HTML, CSS and JavaScript.

1. Create a public GitHub repository.
2. Upload `index.html`, `styles.css` and `app.js` to the repository root.
3. In **Settings → Pages**, set **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save.

The site will then be available at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

## Career research links included

- National Careers Service – Digital sector
- UCAS course search
- GOV.UK – Find an apprenticeship

The site intentionally does **not** hard-code university entry requirements or promise that a student is suited to a specific career. It produces research directions and editable targets.
